# Trouve ton artisan - Plateforme pour la région Auvergne-Rhône-Alpes

## Description
Plateforme web permettant aux particuliers de trouver un artisan dans la région Auvergne-Rhône-Alpes et de le contacter facilement.

**Stack technique :**
- **Frontend** : ReactJS + Bootstrap + Sass
- **Backend** : Node.js + Express + Sequelize
- **Base de données** : MySQL
- **Design** : Maquettes réalisées sur Figma

---

## Prérequis

- Node.js (v18+)
- MySQL 
- npm 
- Git

## Structure du projet

```
.
├── frontend/          # Application React
├── backend/           # API Node.js + Express
├── database/          # Scripts SQL
├── docs/              # Documentation (MCD, etc.)
└── README.md
```

---

## Fonctionnalités principales

- Recherche d'artisans par nom ou catégorie
- Fiches détaillées avec formulaire de contact
- Header / Footer cohérents
- Design responsive (mobile first)
- API sécurisée
